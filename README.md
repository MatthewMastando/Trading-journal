# Tape Journal

Phone-first trading journal, published as a claude.ai artifact: https://claude.ai/artifact/FCRwzsQWGiT5tWwLfvMQ9w

- **Log** — add trades from broker screenshots (Claude reads them) or by hand
- **Plans** — thesis, catalysts, entry/stop/target, R:R before execution
- **Analytics** — P&L, win rate, profit factor, R, equity curve, calendar, setup/mistake breakdowns, Claude review

Data lives in the artifact database (`trades`, `plans` collections), readable only by the owner. `index.html` is the source; republish it to the same URL to update.
